# Voice Test Lab

Test your voice assistant's prompt, then publish it to your web and mobile apps.

## Run it

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py        # open http://127.0.0.1:8001/lab/
```

Open **Settings**, paste your Groq key (console.groq.com/keys), press **Connect**. That is the only setup.

## Use it

| Tab | What you do |
|---|---|
| **Test** | Write the prompt, change its `{{variables}}`, pick moods, press **Run test**. Each mood gets PASS or FAIL with the reason. |
| **Talk** | Press **Start talking** and speak to it (works on iPhone and Android). **Finish** gives you the verdict. |
| **Results** | Everything you tested, talked, or received from your app. |
| **Settings** | Groq key, what counts as a pass, and your app keys. |

**Publish to my app** (on a finished test) makes the web app and every mobile app use that prompt. If it was never
tested or scored under 80% you are asked first. Developers: [`docs/MOBILE_API.md`](docs/MOBILE_API.md).

## Phone

Browsers only allow the microphone on **https**. Easiest: deploy with the included `render.yaml` (Render Blueprint), or
run `cloudflared tunnel --url http://localhost:8001` and open that address on your phone.

## Deploy

`render.yaml` (Render) or `Dockerfile`. Production requires `LAB_API_TOKENS` (your sign-in token, generated by the
blueprint) and, without a persistent disk, `LAB_SECRET_KEY`. Run **one** instance. Settings reference: `backend/.env.example`.

## Develop

```bash
cd backend && pip install -r requirements-dev.txt && python -m pytest -q
```
